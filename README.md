# Dead Ground

A 3D zombie-apocalypse survival game that runs in the browser. Raid a ruined town for loot, dig into the earth for coal and iron, build walls before nightfall, and get an old car running.

## Play

Open `index.html` in a modern browser (Chrome, Edge, Firefox). It needs an internet connection the first time to load Three.js from cdnjs.

To play from a link, turn on GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**. The game will be at `https://warvie.github.io/char/`.

## Features

- Voxel world you can dig and build in. Stone starts about 4 blocks down, with coal and iron deeper.
- Ruined concrete and brick buildings with supply crates to raid.
- Zombies that are slow by day and fast at night. They climb 1-block walls and smash wood, so build 2 high in stone or metal.
- Nail bat, pistol (headshots kill in one hit) and pickaxe.
- Crafting: planks, metal plates, ammo, bandages, repair kits and makeshift fuel.
- Drivable sedans and pickup trucks that need fuel and repairs. Run zombies over, carry a passenger, and use the headlights at night.
- Health, hunger, stamina, day/night cycle and flashlight.
- 2-player split-screen co-op on one computer (keyboard + mouse, and keyboard or gamepad).

## Controls

**Player 1:** WASD move · mouse look · click act · right-click place block · 1–4 / wheel tools · R build material · E use / enter car · Space jump (brake in car) · Shift sprint · Tab backpack · G eat · X bandage · T flashlight

**Player 2:** I K / J L move & turn · U / O look · H act · Y use · N jump · P sprint · B tool · M material · [ eat · ] bandage · \ backpack · or a gamepad
